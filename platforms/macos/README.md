# macOS Platform Integration

This directory hosts macOS-specific platform bindings, packaging scripts, and entitlements:
- `Network.framework` and `SystemConfiguration` interface monitor hooks.
- BSD socket `IP_BOUND_IF` / `IPV6_BOUND_IF` bindings.
- Apple Keychain Services integration for secure proxy credential resolution.
- DMG / `.app` bundle packaging and Apple Notarization scripts.
